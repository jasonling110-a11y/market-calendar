市场日历

财经日历 · 央行议息 · UP 主观点　每日自动更新
订阅到 iPhone 日历 下载 .ics 文件（手动导入） 打开完整日历（网页版）
订阅后怎么刷新？
  1. iPhone：设置 → 日历 → 账户 → 获取新数据 → 拉到底，把「已订阅的日历」设为「每小时」
  2. 如果没自动更新：日历 App → 底部「日历」→ 下拉刷新
  3. 不想订阅了：设置 → 日历 → 账户 → 删除该订阅
订阅地址
如果「订阅」按钮没反应
  1. 请在 Safari 里打开本页（微信内置浏览器不支持 webcal://）
  2. 或用上面的「下载 .ics 文件」，下载后点开 → 添加到日历
  3. 手动订阅：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历
