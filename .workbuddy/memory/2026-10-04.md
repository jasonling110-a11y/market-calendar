### 关键设计决定
- `z-index: 60`（日历原有集合只有 `[5,8,9,20]`，`.sheet` 是 20）。
- 覆盖层挂 `<body>` 下，不做 `.app` 子节点（避开 `.app{overflow:hidden}`）。
- iframe 首次打开后**不销毁**（tab 语义），刷新靠工具栏按钮。
- 加载超时 **30 秒且是「软」的**：1.3MB 单文件 + 沙箱跨境实测仅 ~46KB/s，15 秒会误报；
  即便先弹失败卡片，随后真加载成功会把状态翻回成功。
- **加载结果必须分三类**，不能压成一个 catch：跨域（读 `.location` 抛 SecurityError）=成功；
  `contentWindow === null`（断网/内置错误页）=失败；可读但 `about:blank`=失败。
- 键盘用**捕获阶段**拦 `←/→/t` + `stopPropagation`，Esc 放行 —— 这样不用改日历既有的那行 keydown。
- `#gap` 深链可直接进入（该项目此前完全没用过 `location.hash`，零冲突）。

### 这一轮踩的坑（都已固化进 SKILL §3）
1. **Edge 直连在本沙箱已彻底不可用**：`sandbox initialization failed: Operation not permitted` →
   GPU 进程崩溃 → 进程退出；连带 CDP over WebSocket 以 `CLOSE 1006` 收场（看起来像「ws 被掐」，
   其实只是浏览器死了）；`--remote-debugging-pipe` 也全超时；`--headless=new --screenshot` 不产出文件、
   `--headless=old` 已是空操作。→ 改用 **agent-browser CLI**，一次就通。
2. **`execFileSync` 会阻塞事件循环**，而静态服务器就在同一个 Node 进程里 →
   浏览器报 `Failed to read: Resource temporarily unavailable (os error 35)`。改用异步 `spawn`。
3. **不要在脚本开头 `close --all`**：之后 daemon 会卡死在同一个错误上。
4. 越界：`#mtitle` 之外，日历分段控件用的是 **class `on`** 而不是 `aria-selected`。
5. `preview/index.html` 的 diff 会多出 `const HISTORY = {…}` 那一行的替换 ——
   那是**数据重建**（本地数据 `generatedAt 2026-10-04 12:35`）带上的，不是界面改动。
