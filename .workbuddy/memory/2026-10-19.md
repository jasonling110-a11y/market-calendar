## 🚨 新发现：`git` 的 HTTP2 报错用 HTTP/1.1 即解
- `git push` / `git fetch` 均报 `Error in the HTTP2 framing layer`（连 fetch 都失败）；
  **加 `-c http.version=HTTP/1.1` 后 fetch 与 push 一次成功**，无需改 token / 换通道。
- 本轮走的仍是 packfile fast-forward 通道（`origin/main` 1593d30 → **5d2e577**），3 秒完成。
- 另一个坑：**macOS 没有 `timeout`**，`timeout git fetch ...` 会直接 `command not found` 且**静默不执行**，
  容易误以为 fetch 成功（origin/main 是旧值）。别用 `timeout` 包 git。
- 收尾判据：`git diff origin/main` 为空（0 行），线上 history.js / app.html 与本地 **sha256 完全一致**
  （`7f296150…` / `8ffba95d…`）。curl 必须加 `--http1.1 --compressed`，否则 1.5MB 文件只下到 1.21MB（静默截断）。
